## 1. Second-order pole is a pure gauge mode (symbolic, `s1_second.py`, `s1_tau.py`)
Take C1's pair kernels at |q1| = |q2| = s and total momentum P -> 0, with T = T_Phi(s, eta).
* Only K_Q, K_SPhi and K_Phi2_0 have a pole, and it is a single 1/P^2 term (no 1/P^4).
  - K_S00, K_S0z and K_h have no pole.
  - K_om and K_vT vanish at equal magnitudes.
* K_Q = A_Q/P^2 + O(1), with A_Q = s^2 [2T^2 + (T + eta T')^2].
* pole(K_SPhi) = A_Q'/eta. This is exact once T'' is reduced with the first-order ODE.
* pole(K_Phi2_0) = 4s^2/9 = A_Q(0)/3.

Define tau by (eta^2 tau)' = -eta^2 A_Q with tau regular. In closed form, with x = s eta/sqrt3:

    tau = -sqrt3 s [x^3(2x - sin2x) - 8x^2 cos^2x + 8x sin2x + 4cos2x - 4]/x^5 = -(4/9)s^2 eta + O(eta^3).

Use the k -> 0 Green function G = (eta'/3)(1 - eta'^3/eta^3) and integrate by parts. This gives exactly:
* Phi2 -> -tau/eta, Psi2 -> tau' + tau/eta, delta2 -> -4 tau/eta, delta_T2 -> -tau/eta (each times 1/P^2);
* V2 -> -tau/P^2 + O(1/P). V2 enters only through v2 = grad V2, which is O(1/p).

This is the K=0 gauge mode eta -> eta + eps^2 tau/(2P^2) of A3's gauge.py.
* A spatial dilation constant could also appear. It is excluded because the pole of K_Phi2_0 equals A_Q(0)/3, which is
  zeta^(2)(0) = 0.
* Numerical check (`n0`): A3's pair profiles give P^2 x (AB/2) -> the expressions above, with error O(P^2) (4e-8 at P = 1e-4).

## 2. Third order (symbolic, `s2_third.py`, `s3_gauge_check.py`)
Substitutions: q = k, mu = 1 - p^2/2k^2, KPhi2 = a/p^2 + b + c p^2, Kh = h0 + h1 p^2.
* All of C1's 830-term contracted sources K3c_{Q,SPhi,S00,S0z} have monomial denominators p^2. So each has only a 1/p^2 pole.
* The pole depends only on a = -tau/eta and on T(k). The regular parts b, c, h and the tadpoles drop out.
* With tau' = -A_Q - 2tau/eta, every pole equals **exactly** the source generated by c x (A3's gauge formula):
  dPhi3 = 3tau T' + 6tau T/eta, dPsi3 = 3tau T' + 6(tau' + tau/eta)T, dV3 = 3tau T_V' + 3tau' T_V,
  ddelta3 = 3tau T_delta' - 12 tau T_delta/eta.
  sympy solves for c and finds c = 2 for all four sources. The factor 2 comes from 2A(q)B2.
* The C3 pole matches: C1's 16/(9(1-mu)) = (32k^2/9)/p^2, and 2 lim_{eta->0}[3tau T' + 6tau T/eta] = 32k^2/9.

Because the regular solution is unique, the poles of Phi3c, Psi3c, delta3c and V3c are exactly (2/p^2) x the gauge shifts.

## 3. Residues = gauge response; explicit forms; why they cancel
**Why only these poles matter.** Each term has a single second-order factor.
* Scalars are Laurent series in p^2.
* Gradients and v2 give p_j/p^2. After the phi-average around khat these terms are either odd (they vanish) or come with
  p.khat = p^2/2k, which makes them O(1).
* So the residue is the response of the k-leg map to the homogeneous pole fields alone. That response is the gauge response with
  tt = tau/(2k^2).

**Explicit residues** (`n3`). Notation: I1 = -k^2(nu^2 - 1/3) T_V(eta) e^{ik nu chi} (first-order shear on the ray), with
Delta_l = (1/2i^l) int dnu P_l R.
* R_clock = 3 tt(eta_o) I1(eta_o). This is pure l=2: Delta_2 = (2/5)k^2 tt(eta_o) T_V(eta_o) = 0.2393147529. It comes from
  deta_o2 -> -tt(eta_o).
* R_emi = -3 tt(eta_*) I1(eta_*). It comes from deta_e2 -> -tt(eta_*).
* R_TD = 3 int tt (ik nu) I1 deta. It comes from Dx2_radial -> -tt(eta).
* R_v3 = -3 int [tt d_eta I1 + tt' I1] deta, with d_eta acting on T_V.
* R_loc21 = 6 int tt' I1 = -R_k2r. The radial k2 piece comes from n.k2 -> -(Phi2 + Psi2) = -tt'.

**Cancellation:**

    R_v3 + R_TD = -3 int (d/deta)[tt I1(eta, n chi)] = -3[tt I1]_o + 3[tt I1]_*,

which cancels R_clock + R_emi. In addition R_loc21 + R_k2r = 0. This holds identically in n, so for every l.

Each formula matches the engine's channel to <= 1.2e-14 for l = 0..8. They were written by hand from the L3 group structures and
checked numerically; they are not a symbolic reduction of C2's lists.

**Physical reason.** Under the coordinate change eta -> eta + tt(eta), with x unchanged:
* the observer's proper-time clock, the T_phys = T_* surface, the label and the canonical triad are all invariant;
* the ray, the clock reading and the emission time shift by tt, and v gets a Lie-derivative shift;
* Theta is a scalar, so the total response is zero.
